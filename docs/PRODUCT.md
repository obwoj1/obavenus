# Obavenus

Obavenus is an original Electron desktop app inspired by the broad product category of Universe. The implementation will use its own code, visual language, copy, and assets.

## Product direction

Start with a macOS desktop assistant that combines AI chat with a project workspace. Keep the first version small enough to run locally, then add capabilities in independently reviewable steps.

Obavenus is also expanding toward an optional local-first study workspace. The observed feature scope and staged implementation order are tracked in [STUDY_WORKSPACE_PLAN.md](STUDY_WORKSPACE_PLAN.md).

## Design boundaries

- Treat REA output as technical evidence about the installed app, not as source code to copy.
- Do not reuse Universe source, assets, copy, secrets, or private service endpoints.
- Build new UI and behavior from the product goal and user feedback.
- Keep local file and process access explicit and narrow.

## Current implementation

The current app combines AI chat, local project spaces, and optional Gmail search. Each selected folder is a local space; conversations are associated with the active space and reopen its folder when selected. Spaces and conversation history do not sync or collaborate across accounts. Conversation history is encrypted with macOS OS-backed storage; existing renderer history is migrated at startup. Conversations can be searched, renamed, deleted with confirmation, and exported as Markdown, including attached reference context, specialist findings, and project artifact change notes. The active chat cannot be deleted while its response is running. The personal profile accepts TXT, Markdown, DOCX, and PDF resumes, including offline OCR for scanned PDFs. OpenAI can connect through Sign in with ChatGPT or an API key; Gemini supports Google OAuth for the Gemini API using a user-selected Cloud project; Claude supports the official Claude Code account sign-in for local one-response chats, plus an Anthropic Console API key for hosted team/API calls; Grok supports official Grok Build browser sign-in for local one-response chats, plus an xAI API key for hosted team/API calls. Account-backed Claude and Grok chats use their installed CLI and local account terms; Obavenus does not store their credentials. Claude Code, Codex CLI, and Gemini CLI can also run through the user's existing local CLI installation and sign-in without a new Obavenus API key. Ollama runs open models locally through its loopback-only API. Project files stay local until explicitly attached to a message; bounded selectable text from PDF, Word, Excel, and PowerPoint files can be inspected locally. Scanned PDFs are recognized on-device. Gmail search reads message metadata and snippets; Obavenus can create Gmail drafts when explicitly requested, but never sends email.

Solo responses stream text into the conversation as it arrives for OpenAI, Claude, Gemini, Grok, ChatGPT account sign-in, and local Ollama. Provider deltas are passed from the main process to the renderer over scoped Electron IPC; the app does not store or forward stream chunks to another service.

The Federal Role Finder parses pasted job and offer blocks into titles, agencies, and locations. It always offers official USAJOBS search links; with a user-provided USAJOBS API key it also aggregates open agency-specific and federal IT-series announcements in-app, filters by location/full-time/minimum salary, deduplicates records, and shows available salary, closing date, requirements, required documents, and application steps. Credentials are encrypted locally. Application submission and definitive eligibility decisions remain on USAJOBS and with the applicant.

The optional Study space keeps courses, assignments, due dates, checklists, editable assignment drafts, encrypted local assignment attachments, notes, decks, daily focus items, review state, and reminder preferences encrypted on this Mac. It can import course files for deterministic search, extractive outlines, generated flashcards, quizzes, and review queues. Search can cover one selected course or the entire library; a grounded-question action prepares an editable prompt with up to six bounded, cited excerpts and does not send it until the user submits the prompt. Assignment tools scan explicit requirements, explicitly named grading criteria and skills, suggest instructor clarification questions, draft editable plans and review checklists, seed an editable assistant prompt with matching course excerpts and user-selected assignment files, save assistant responses into a selected assignment draft, and export drafts to Word. Assignment submissions remain with the student. Opt-in desktop reminders run while the app is open with configurable quiet hours. A local digest can be reviewed, copied, saved as a Gmail draft, or scheduled to create one Gmail draft each day while Obavenus runs. The schedule honors quiet hours and never sends mail. Canvas PAT sync imports active courses, assignments, modules, and supported files linked in modules; file downloads are bounded and extracted on-device and sync preserves local assignment drafts and attachment references. Compatible HTTPS MCP services can expose read-only tools, advertised resources, and simple resource templates to assistant runs; resource URIs must match the connected server's catalog and returned content is bounded. A separately opt-in local MCP server lets compatible clients read courses, assignment prompts, flashcards, and bounded course-file excerpts from this Mac; it uses an OS-encrypted bearer token and loopback-only HTTP, and excludes private assignment drafts and submission actions. The product does not submit assignments or expose mutating MCP tools.

Team runs include a read-only mode and an explicit per-run project-write mode, and local CLI agents now have provider-specific edit modes that require an open project. Codex uses its workspace-write sandbox; Claude disables Bash and web fetch while enabling accepted file edits; Gemini enables its auto-edit mode. Review changed files in Git after a run. Scheduled local jobs stay read-only.

Local CLI runs use the selected project working directory (or app data without a project), read-only/default CLI permission modes, a bounded timeout, and bounded output. The user can stop an active Claude Code, Codex CLI, or Gemini CLI run from the composer; Obavenus sends SIGTERM to that local process and records the stopped run in conversation history. Provider and team requests also accept Stop: Obavenus aborts the in-flight provider request and prevents the team from starting further model steps. Claude account sign-in is initiated through the official Claude Code CLI from Settings; Codex and Gemini CLI continue to use their own existing CLI sign-ins.

The composer includes a bundled local workflow library for feature planning, codebase exploration, change review, debugging, technical documentation, and converting an idea into steps, alongside user-created workflows. Users can select up to three workflows per request or mark up to five custom workflows as always-on; enabled workflows are included in every new provider, team, local CLI, remote, and scheduled run, including future occurrences of recurring tasks. Team agents receive the same instructions. Workflow settings persist encrypted on this Mac and do not rewrite saved conversation history.

Users can queue a prompt for a later run with a local CLI or the configured AI provider, once, daily, or every weekday at a chosen local time. Provider-backed tasks use the current provider settings when they run and can use the read-only specialist team, project context, and Gmail search tools. Scheduled work cannot write project files or control the browser. Scheduled prompts and results are encrypted in the app's local data store, queued schedules can be cancelled, and completion sends a desktop notification when supported. Each occurrence gets up to three attempts; interrupted tasks recover on restart. Tasks run only while the app is available and missed queued work is picked up at next launch; this is not a cloud scheduler.

The team can automatically choose relevant saved profiles or launch up to twelve user-selected custom specialists concurrently with its built-in analysis and review agents. Automatic selection uses the planner's validated profile IDs, with deterministic keyword ranking when the planner gives no usable assignment. If a specialist run fails, the lead revises the plan and retries that specialist once while preserving completed findings. Browser research is opt-in per run and offers either the isolated, persistent Obavenus Research Browser or a paired extension for the user's existing Chrome profile. The Chrome bridge binds to loopback, accepts only the pinned extension origin, and reads the active tab after the user grants site access. In paired Chrome, the analyst can request to fill one uniquely labelled ordinary text field at a time; a native confirmation displays the page, field, and exact text, and filling never submits the form. Password and verification-code fields are excluded. Each control click also requires native confirmation, and approval is invalidated if the selected tab or page changes. Project-write mode can create bounded text artifacts including Markdown, CSV/TSV, HTML, and code, plus native `.xlsx`, `.docx`, and `.pptx` files inside the selected project.

Obavenus can run provider CLIs over locally saved SSH machines, using existing CLI sign-ins and SSH host-key verification. Remote jobs can be explicitly detached so they keep running if Obavenus closes, or scheduled to start within 30 days; their local records and results are encrypted on this Mac, while the remote prompt, logs, and outputs stay in a private job folder on that machine until the user deletes them. Local cancellation works for queued remote runs and active CLI processes. Machine labels and host aliases are also encrypted locally. Cloud-synced shared spaces are not implemented. Project memory is encrypted on this Mac and scoped to the selected folder; saved notes are included in later team requests for that project. Saving requires the user to enable project-write mode for that run. It is not shared or synced.

Root `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, and `.github/copilot-instructions.md` files are loaded as bounded project guidance for provider, team, scheduled, and local CLI runs. Guidance is labeled as untrusted project data and cannot override the user's request or Obavenus access limits. Files are read only from the selected project and never modified by this feature.

Team agents can search source and documentation text for literal strings and get bounded line-numbered matches. They can also inspect Git branch/status, bounded staged or unstaged diffs, and up to twelve recent commit summaries through fixed read-only Git commands. Results are scoped to the selected folder, disable external diff/text conversion, and omit untracked file contents; agents use the project reader for those files.
