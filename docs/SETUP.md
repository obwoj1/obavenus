# Local setup

Project previews support plain text files up to 64 KB plus PDF and Office files up to 10 MB. PDF and Office extraction happens locally and is capped at 60,000 text characters; PDFs are limited to 200 pages. The bundled OCR engine recognizes up to 20 scanned PDF pages on this Mac. Previews stay on the Mac unless you explicitly add the extracted text to a message; attached context is shown in the composer before sending.

The personal profile can import a resume from TXT, Markdown, DOCX, or PDF. Scanned PDF pages are recognized with the bundled offline OCR engine; up to 20 scanned pages are processed and the saved profile text is limited to 50,000 characters. Resume extraction stays on this Mac.

Use Node.js 24 and npm. From the project folder:

```sh
npm install
npm run dev
```

Obavenus can choose and remember a project folder, list its top-level entries, and preview plain text files up to 64 KB. Previews stay local unless you explicitly add a file to a message; the composer shows attached files before sending. Conversations persist locally in macOS OS-encrypted storage and can be reopened from **Recent work**. For OpenAI, choose **Sign in with ChatGPT account** or **Use OpenAI API key** in **Settings**. ChatGPT account access depends on account eligibility, token-sharing consent, and OpenAI approval of the app; it is separate from API billing. For Gemini, choose **Sign in with Google account** and provide a Google Cloud project ID plus a Google OAuth desktop client. Enable the Generative Language API and configure OAuth consent/test users in Google Cloud. Gemini API usage is billed to that Cloud project, not a Google AI subscription. The OAuth flow requests `cloud-platform` and `generative-language.retriever` scopes; account eligibility and Google OAuth verification settings apply. Claude and Grok currently use API keys in Obavenus. Claude subscription sign-in is supported in Claude Code; xAI's public API uses API keys. API keys and OAuth credentials are encrypted with Electron safeStorage and are never returned to the renderer. Chat history and explicitly attached file text go to the selected provider only when you press **Send**. OpenAI requests set `store: false`; provider retention policies can differ.

For a no-new-API-key option, install and sign in to Claude Code (`claude`), Codex CLI (`codex`), or Gemini CLI (`gemini`) in Terminal, then restart Obavenus and choose that CLI from the composer mode menu. Obavenus discovers standard Homebrew, `~/.local/bin`, and NVM locations. Local runs use the selected project as their working directory (or Obavenus app data when no project is selected), receive recent conversation and only explicitly attached files, and use read-only/default permission modes. The app does not enable permission bypasses. Interactive runs have a three-minute timeout and a 2 MB output cap. Scheduled tasks can run for up to two hours with an 8 MB output cap while Obavenus remains open. CLI sign-in is managed by each CLI provider; Gemini CLI may require Google Cloud/API setup according to its own configuration.

While a local CLI, provider, or team run is active, choose **Stop** in the composer. Obavenus sends SIGTERM to the local CLI process or aborts the current provider request; team runs stop before starting another model step. The stopped request remains in local conversation history.

For a local open model, install Ollama, run `ollama pull qwen3` in Terminal, and start the Ollama app. Select **Ollama · local models** in Model settings, refresh the installed model list, and choose its tag (for example `qwen3:8b`). Obavenus sends prompts only to the local Ollama service at `127.0.0.1:11434`; it does not send those requests to a hosted model provider. Models run on your Mac and their speed and tool-calling ability depend on the model and hardware.

For a remote machine without an Obavenus cloud service, configure an SSH host alias and key in `~/.ssh/config` on this Mac, and install/sign in to Claude Code, Codex CLI, or Gemini CLI on the remote host. Select an **SSH · …** mode, choose **Manage machines**, and save a name and alias after its test connection succeeds. Machine entries are encrypted on this Mac; SSH keys stay in your SSH setup. Optionally enter an absolute remote project path for read-only analysis. Remote edit modes require that path and apply the same per-run write controls as local CLI modes. SSH uses existing known-host verification and `BatchMode`; connect to the host once from Terminal first if you need to verify its host key or load an encrypted key into your SSH agent. Check **Keep running if this app closes** to detach a run. The optional **Start at** field queues it on that host for up to 30 days ahead; the remote machine must remain online, and its CLI must remain signed in. Use **Remote jobs** to reconnect, inspect results, stop a queued or running task, or delete its remote prompt and output files.

For local file implementation, select one of the **edit project** modes. This requires an open project and grants that run the provider's project-edit mode (Claude Code accept-edits with Bash/WebFetch disallowed; Codex workspace-write sandbox; Gemini auto-edit). These provider controls differ; commands are not run with a permission-bypass flag. Review the resulting project diff in your usual Git tools before keeping the changes. Scheduled runs remain read-only.

Choose a reusable workflow beside the composer mode to guide common requests such as feature planning, codebase exploration, change review, debugging, documentation, or turning an idea into steps. These bundled instructions stay local and can be combined with either a provider-backed or local CLI run.

To schedule a local task, choose a local CLI mode, enter its prompt, select **Schedule**, and choose a time. The task uses the project folder selected when it was queued, runs read-only, and appears under **Scheduled tasks** where queued tasks can be cancelled. Task prompts/results are encrypted with Electron safeStorage. The scheduler runs while Obavenus is open; if the app is closed or the Mac sleeps through the scheduled time, an overdue task is picked up when the app next runs. A desktop notification appears on completion when macOS notifications are enabled.

Select **Team · write project files** to let the implementation specialist create or replace files in the open project for that run. The default **Team · read-only** mode does not write. All writes are confined to the selected project and block hidden paths, symlinks, dependencies/build/release folders, and oversized files. Text outputs include Markdown, CSV/TSV, HTML, and code; dedicated artifact tools create native `.xlsx`, `.docx`, and `.pptx` files with an 8 MB cap. The answer shows which paths it created or updated. Local CLI providers may have their own tools; Obavenus uses their provider-specific project-edit modes for local edits.

For isolated web research, choose **Team · research browser**. For your existing signed-in Chrome profile, select **Set up Chrome** beside the Research Browser controls. In the opened folder, go to `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the folder. Click the Obavenus extension, optionally grant site access, then choose **Connect to Obavenus** and approve pairing in the desktop app. Now choose **Team · signed-in Chrome** in the composer. The analyst can navigate and read the active tab, follow links, and request to activate a visible button. It can also request approval to fill a uniquely labelled normal text field; Obavenus shows the exact page, field, and text in a native prompt. Filling does not submit forms, and password and verification-code fields are blocked. Obavenus displays a separate native confirmation for each click; declined actions are not performed. The Chrome extension disconnects when Obavenus closes. Page text is treated as untrusted reference material.

Leave the specialist picker empty to have the lead choose relevant saved profiles for that request, with deterministic relevance matching if its assignment is unclear. Manually select up to twelve profiles to control the lineup. The profiles run concurrently alongside the built-in analysis and review agents. If a specialist fails, the lead attempts a revised plan and retries that specialist once; completed findings remain in the final synthesis.

In **Find federal jobs**, paste offer/job descriptions and use **Build official search links** without credentials. For in-app open-announcement aggregation, request a USAJOBS developer API key from the official developer portal, then expand **Connect USAJOBS API**, enter the email used for the request and key, and save. Obavenus encrypts the key on this Mac and sends searches directly to USAJOBS. Current queries cover the listed agencies plus the 2210 IT occupational series and public announcements. Confirm each listing's eligibility, closing date, required documents, and application instructions on its official announcement; Obavenus does not submit applications.

Gmail is connected separately from the AI provider. Create a Google Cloud project, enable the Gmail API, and create an OAuth client of type **Desktop app**. Enter its client ID and client secret in Obavenus under **Gmail** and approve the Google sign-in. Obavenus requests only the `gmail.readonly` scope for Gmail, uses PKCE for sign-in, and stores OAuth tokens and the client secret using Electron safeStorage. Search result snippets are only sent to the AI if you choose **Attach snippet to next message** and then press **Send**. Gmail OAuth consent-screen testing may require adding your Google account as a test user.

Use **Close** in the workspace panel to remove the saved folder selection. Keep secrets out of the renderer and Git history.

The source repository is public at https://github.com/obwoj1/obavenus.

To build a local Apple Silicon app bundle, run `npm run pack:mac`. To create a DMG installer, run `npm run dist:mac`; output goes under `release/`. These local builds are unsigned and not notarized, so macOS may require you to approve the app the first time you open it. Public distribution needs Apple signing and notarization.
