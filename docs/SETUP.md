# Local setup

Use Node.js 24 and npm. From the project folder:

```sh
npm install
npm run dev
```

The first screen is a local UI prototype. It can choose a project folder, remember that folder on this Mac, and display its top-level file names. It does not read project-file contents or call an AI model yet. Use **Close** in the workspace panel to remove the saved folder selection. Keep secrets out of the renderer and Git history when provider support is added.

The source repository is private at https://github.com/obwoj1/obavenus.
