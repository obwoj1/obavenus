# Local setup

Use Node.js 24 and npm. From the project folder:

```sh
npm install
npm run dev
```

The first screen is a local UI prototype. It can choose a project folder, remember that folder on this Mac, and display its top-level file names. You can click a listed file to preview plain text up to 64 KB; Obavenus does not send it anywhere. Conversations and placeholder replies persist locally and can be reopened from **Recent work**. The app does not call an AI model yet. Use **Close** in the workspace panel to remove the saved folder selection. Keep secrets out of the renderer and Git history when provider support is added.

The source repository is private at https://github.com/obwoj1/obavenus.
